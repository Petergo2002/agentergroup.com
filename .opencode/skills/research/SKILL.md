## When to Use
Use this skill when the user asks you to:
- Research a topic, library, framework, or concept
- Find examples or documentation
- Look up APIs, patterns, or best practices
- Search for solutions to technical problems

## Workflow

1. **Understand the query** - Identify what information is needed and in what form (code examples, docs, tutorials, etc.)

2. **Choose the right tool**:
   - `websearch` - For current information, tutorials, recent developments
   - `codesearch` - For code examples, library usage, patterns, API references
   - `webfetch` - For fetching specific URLs (docs, articles)

3. **Search strategically**:
   - Start with websearch for overview/background
   - Use codesearch for specific implementation patterns
   - Combine queries if needed (e.g., "React useState hook examples", "Python pandas dataframe filtering")

4. **Compile results** - Summarize findings with relevant code snippets, links, and key takeaways

## Tips
- Adjust token count based on needed depth (1000 = focused, 50000 = comprehensive)
- Use specific queries for better results
- Prefer codesearch for programming-related questions
- Include the current year (2026) in searches for recent information
